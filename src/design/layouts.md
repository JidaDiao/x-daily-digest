# 设计灵感页 · 多版式工具箱（可选，非每日硬规则）

> **用户 2026-11-03 更正**：设计灵感页**不必**每天大改界面壳；每天根据反馈优化的是**选题/内容与拼接**。  
> 「整体风格 / 动画 / UI / UX / 卡片图表每天不一样」交给**叼报资讯页**（用收藏元素拼接，见 digests `DAILY.md` 版式原型 v2）。  
> 本文件保留六种 layout，仅在你**主动想换壳**时使用；缺 `_layout.json` 时 build 用默认纵向列表，**不会失败**。

## 六种版式（可选）

| id | 名 | 一眼差在哪 |
|---|---|---|
| `magazine` | 杂志封面流 | 第 1 卡全宽巨封面，其余栅格 |
| `workbench` | 工作台 | 分区/分栏浏览 |
| `wall` | 卡片墙 | 密网格 |
| `timeline` | 时间轴 | 左轴右卡 |
| `deck` | 一次一条 | 横向 snap |
| `index` | 索引墙 | 先索引再详情 |

用法：主动写 `blocks/_layout.json`（见 `_layout.example.json`）才会套用；否则默认 list。

## 设计页真正的每日硬规则（选题侧）

1. 读 GitHub feedback → preferences / design-tokens  
2. ≥4★ / 收藏优先；≤2★ / avoid 不碰  
3. 8 条 Web4+App4；每期 ≥1 好看的卡片（界面）  
4. 今日拼接用收藏；上期站点/元素不用
