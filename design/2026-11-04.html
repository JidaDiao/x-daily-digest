纸卡详情页拿起来读

示例文案：详情像一张从桌上拿起的纸。读完放回去，桌面还在原处，用户不会迷路。

来源lthero.com 桌面材质米黄纸 · 大投影层级黑胶囊 / 描边胶囊

本期卡片条。详情不是弹一个白色模态框，而是一张米黄纸从暗桌面上浮起来：大投影把纸「拿离桌面」，顶栏是等宽小字的出处和「放回桌上」描边胶囊，标题旁一笔手写绿字，标签是黑底胶囊加一颗红点。看纸色、投影深度和三种胶囊（黑实心标签、黑实心主按钮、描边次按钮）怎么分出层级。点「放回桌上」再点纸角可以重来。

怎么操作

接 5★ 的 Lthero 散落成桌和 4★ 的 Orb 贴纸：都是把内容当成可以摆弄的小物件。mmm.page 官网首页本身就是 demo，「tap EDIT in bottom right, then tap anything」。值得学的是三个状态：浏览时没有任何手柄；编辑时每件东西出现虚线框提示可动；拿起时旋转加大、投影拉长、层级置顶，放下后回到原角度偏移。

Web拖拽贴纸编辑模式拼贴交互
mmm.page ↗
怎么操作 · 为什么新鲜
怎么操作
先点右下角绿色 EDIT：贴纸都出现虚线框，按住拖到任意位置，拿起时会歪一下、投影变大；再点 DONE 退出编辑。
为什么新鲜
编辑和浏览是同一张页面，只靠一个按钮切换；拿起物件时的歪斜和投影让「拖动」像在桌上挪贴纸，而不是拖控件。
关键参数
  • EDIT 按钮薄荷绿、紫色 CTA、黄色胶带标题，来自官网截图（估计色值）
  • 拿起 --tilt 默认 6deg、scale 1.06、投影 0 18px 30px rgba(0,0,0,.28)（demo 增强）
  • 拖拽用 pointer 事件 + touch-action:none，只在编辑态生效
