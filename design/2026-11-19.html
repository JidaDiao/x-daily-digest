mmm.page · 自由摆放的贴纸拖拽

拖一拖，桌子就是你的版式
✦hello
◐mmm.page
✿拖我

mmm.page 把个人主页做成一张可以随便摆东西的桌子：贴纸、卡片、链接都没有格子管着，想放哪就放哪。拖拽本身没有确认、没有吸附、没有对齐线——松手即落定，位置就是排版。这个 demo 只复刻一件事：按住、拖走、落定时的那一下轻回弹。

怎么操作 · 为什么新鲜
怎么操作
按住一张贴纸拖到任意位置，松手它会轻轻落定；点右下角重播，看三张依次掉进桌面。
为什么新鲜
自由摆放是 mmm.page 的核心：页面不是栅格，是一张桌子；拖拽没有吸附网格，位置本身就是内容的一部分。
关键参数
  • 拖拽用 pointer 事件 + touch-action:none（原站自由摆放，据 2026-11-04 收藏记录）

  • 贴纸圆角 10px、阴影 0 8px 24px -12px rgba(0,0,0,.25)（demo 估计）
  • 拖动时放大 1.06、阴影加深、旋转归零（demo 增强）

Family · 点一张功能卡，弹性撑开

一张卡撑开，其余卡片让位

Family 的钱包页是一叠功能卡：点一张，它弹性撑开露出最近的三笔和入口，其余卡片往下让位；再点收起。没有页面跳转，没有弹窗，状态切换就发生在列表里。这个 demo 只复刻一件事：点开时那一下带回弹的撑开。

怎么操作

Lthero · 印章 / 警戒胶带 / 模切贴纸

三种好看的卡：印章 / 胶带 / 贴纸
CAUTION · 小心轻放 · CAUTION
✦好设计
先让手有事做

Lthero · 从桌上拿起一张纸卡来读

一张纸卡，拿起来才好读

Lthero 的桌面上放着一张纸卡：平放时微微倾斜、带着桌面的阴影，像随手搁下的便签；点一下把它拿起来——卡片回正、浮起、阴影变大变软，正文才完整露出来。看的还是同一张卡，姿态变了，阅读就开始了。界面和交互在这里是一件事：卡片的长相决定了它值得被拿起来。

纸卡桌面拿起
lthero.com ↗原站截图取不到，只留链接
怎么操作 · 为什么新鲜
怎么操作
点一下纸卡，把它从桌上拿起来；再点一次放回去。
为什么新鲜
拿起不是打开新页面：同一张卡片换个姿态，阅读状态就变了；Lthero 的桌面隐喻里，动作就是导航。
关键参数
  • 卡片圆角 6px、纸面 #f7f3ec、桌面底 #e8e2d6（demo 复刻）
  • 拿起过渡 .45s cubic-bezier(.22,1,.36,1)（demo 估计）
  • 平放阴影 0 4px 12px -6px rgba(0,0,0,.3)；拿起阴影 0 24px 40px -16px rgba(0,0,0,.35)（demo 估计）
  • 卡片文案为 demo 占位

Cash App · 加钱成功，一颗绿勾弹出

绿勾一弹，钱到了
  1. 1绿勾先弹出来：#00D632 圆形对勾，scale 0→1.08→1
  2. 2大字确认：You added $21，从 Bank of America debit 卡来
  3. 3底部只有一个黑胶囊 Done，点它回去

Mobbin 原图 · 未改动 · 299×678

Cash App 的加钱成功页只做一件事：亮绿对勾弹出来，一行大字告诉你加了多少钱、从哪张卡来，底部一个黑胶囊 Done。没有第二操作，没有“查看详情”，连金额都是 17px 以上的整句。值得学的点：成功态的最高礼貌是不挽留用户。

怎么操作 · 为什么新鲜
怎么操作
先看绿勾弹出来，再读一行金额确认，最后点底部黑胶囊 Done 回去。
为什么新鲜
成功态不解释流程：一个对勾加一句话就够了，Cash App 把确认做成了一个标点，而不是一页说明。
关键参数

  • 黑胶囊 Done：#000 底白字、999px 圆角、min-height 48px、:active scale(.97)（cashapp-done-pill）
  • 页面大留白，成功信息只有对勾加一句话（token）

Neuecast · 首页信息流

Today / Yesterday，两组就够了
  1. 1Today 1、Yesterday 3：大标题分组，后面跟浅灰计数
  2. 2组内是浅灰底圆角卡片：封面加标题加两行简介
  3. 3底部浮着 Now Playing 迷你条：小封面加一行标题加黑色圆按钮

Mobbin 原图 · 未改动 · 299×678

Neuecast 的首页没有推荐算法的架势：Today、Yesterday，两个大标题分组，组名后面跟一个浅灰计数，组内是一张张浅灰底的圆角卡片——封面、标题、两行简介、时长。底部还浮着一条迷你 Now Playing。克制的点在于，信息流的层级只用三样东西表达：字号、灰度、圆角。

Superlist · 勾掉一条任务

圆圈一点，任务就完了
  1. 1Inbox：一张极素的清单，大标题加三行任务
  2. 2每行行首一个圆圈，点它就勾掉
  3. 3底部 + New task 胶囊，随时加下一条

Mobbin 原图 · 未改动 · 299×678

Superlist 的 Inbox 是一张极素的清单：大标题、一条浅灰提示卡、然后是带圆圈的任务行。完成不需要打开任务、找按钮、再确认——点一下行首的圆圈，任务就勾掉了。底部 + New task 胶囊随时能加下一条。值得学的点：最高频的动作值得最短的路径。
