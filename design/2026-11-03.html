怎么操作 · 为什么新鲜
怎么操作
点「Deploy」看状态点呼吸 → 进度条走完 → Ready toast；可调脉冲时长与强调色。
为什么新鲜
部署反馈被收成一颗会呼吸的状态点，再接一条细进度，最后 Ready 轻轻弹一下——克制、可感知。
关键参数

  • 脉冲 --pulse 默认 900ms；进度走完约 1.6s；Ready toast 220ms ease
  • 色值按公开产品页估计

Orb Social · 点赞按钮贴上一枚贴纸

信息流帖子 → 点赞时弹出贴纸 → 贴上后计数跳动
  1. 0s信息流里一条帖子，爱心还是空的
  2. ~2s点赞，弹出贴纸盘
  3. ~5s贴纸贴上爱心，计数跳动
  4. ~8s流程收束

Mobbin 原视频 · 已压缩、无声

一句话亮点：点赞不是灰心变红心，而是给爱心按钮贴上一枚表情贴纸，计数跟着跳一下。值得学：把「反应」做成可收集的小物件，反馈有记忆点，又不打断信息流。

Lapse · 冲印式 snaps 一点点显影

拍完 → 胶片式显影过程 → snaps 出现在卷轴
  1. 0s进入待显影 / 卷轴
  2. ~4s影像开始从暗到亮浮现
  3. ~10ssnap 清晰落地，可继续下一张

Shangri-La Circle · 奶油底山脉金会员卡

首页会员条 → 奶油山脉金卡弹层 → Wallet 预览 → 识别引导
  1. 0s首页：淡金会员条嵌在水彩山景里
  2. ~2.5s弹层：奶油底山脉插画金卡 + QR + Refresh
  3. ~5sApple Wallet 预览：同款卡面可加入钱包
  4. ~7.5s引导页：Recognition 文案托着卡面模型

Mobbin 原图 ×4 拼成（无原视频）· 已压缩、无声

一句话亮点：会员卡不是塑料条，而是奶油纸感 + 水墨山脉插画 + 衬线姓名的金卡弹层，底部大 QR 与 Add to Wallet。值得学：卡面本身就是品牌记忆点——纹理、插画、字体层级一起把「贵」说完，几乎不靠渐变炫光。
