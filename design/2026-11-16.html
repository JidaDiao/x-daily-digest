raindrop.io

按住一张卡，拖到左边的收藏夹上试试

拽住日程块底边上下拖，时长跟着手指长

Notion Calendar 的时间块是「所见即所得」的时长：块多高，会议就多长。拽住底边往下拉，块长高、结束时间跟着变；松手自动吸附到 15 分钟刻度。比起在弹窗里改两个时间框，手指直接量出了时长。

日历拖拽时间块
Notion Calendar ↗
怎么操作 · 为什么新鲜
怎么操作
按住日程块的底边上下拖，块跟着变长变短，松手后时间自动对齐到 15 分钟。
为什么新鲜
不用打开编辑框改时间：时长就是块的高度，改多久、拖多长一眼就能对上。
关键参数
  • 事件块蓝 #1313ba / 淡紫底 #cbcbef / 背景 #f6f6fc（notion.com 日历页 CSS 实测）
  • 圆角用 tatami radius-500 档，约 8px（按源码估计）
  • 松手吸附 15 分钟为 demo 设定：原站按网格吸附
  • 拖拽中时间标签实时更新为 demo 增强

Tana · 打个 #，这一行就变成带字段的对象

Q4 路线图#项目

#项目 Q4 路线图 · 新想法

点行里的 #，或者在行尾输入 #，选一个标签试试

Tana 的超级标签把「打标签」变成了「建对象」：输入 # 弹出补全，选中 #项目，这行不再是纯文本，而是有状态、负责人、截止日期的对象。演示里点 #项目，行会翻成一张小卡，字段可以直接点改。

大纲标签对象
Tana Outliner ↗
怎么操作 · 为什么新鲜
怎么操作
在行里输入 #，弹出标签菜单，选一个 #项目，整行变成带字段的对象卡。
为什么新鲜
标签不是装饰：选中的那一刻，行就长出了字段——标题、状态、负责人都能就地填。
关键参数
  • 标签紫 #963f9b（tana.inc 首页 CSS 实测）
  • 墨色 #0c0805 / 纸白 #fbfbfb（首页 CSS 实测）
  • 圆角 radius-2 档 + 999px 胶囊（首页 CSS 实测）
  • 过渡 background-color .12s（首页 CSS 实测）
  • 对象卡字段为 demo 设定：原站字段由所选超级标签定义

HEY · Screen in / out 分拣按钮

两扇门 · 进 Imbox 还是进 Screener

设计周报 · 今早 9:41

本周 8 个新交互，都能直接上手玩

这周挑了 4 个 Web 动效和 4 个 App 原图：拖拽、拉伸、打标签、分拣……点开就能试，不用先看完再决定留不留。

HEY 的第一课不是读邮件，是决定邮件的去留：Screen in 进 Imbox，Screen out 进 The Screener。两个按钮都很大、都放在拇指够得着的地方，点完卡片滑走，留一个 5 秒撤销——分拣的成本被压到了一次点击。

邮件分拣按钮
HEY ↗
怎么操作 · 为什么新鲜
怎么操作
点 Screen in，邮件滑进 Imbox；点 Screen out，邮件滑进 The Screener，底部留一个撤销。
为什么新鲜
分拣不是删邮件：两个大按钮就是收件箱的门，进哪扇、当场决定，不用先读完再归档。
关键参数
  • Blurple #5522fa / Canary #fff5ca / Cobalt #0074e4 / Coral #f95c5c（hey.com root.css 实测）
  • 墨色 rgb(35,28,51)（root.css 实测）
  • 按钮圆角 0.25em（elements.css 实测）
  • 滑走 + 撤销条为 demo 设定：原站分拣后邮件即离开列表

Speechify · 生成摘要：先选长度 / 模式 / 页数

先选长度 / 模式 / 页数，再点生成
  1. 1粘贴链接或文章，顶部是 Length 三档
  2. 2Mode：Paragraph 段落 / Bullet Points 要点
  3. 3Pages：All Pages / 1 page

Mobbin 原图 · 未改动 · 299×678

Speechify 的生成摘要页把选择放在生成之前：长度三档、模式两档、页数两档，选完再点蓝色大按钮。没有让 AI 先猜、用户再改——摘要的形状由人先定，机器只负责填内容。
