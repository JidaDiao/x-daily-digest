一句话亮点：进视口后，七根淡紫柱子从底往上依次长满，顶部那颗「12.4k」小数字跟着轻微上跳一下。Fathom 是隐私优先的分析工具，首页主色是一种不刺眼的紫 hsl(250,80%,62%)，灰阶带一点点绿相（hsl(140,…)）。这里只复刻仪表盘里「柱状图填满」这一下：白卡、细灰网格、柱子用 --purple-fade 到 --purple 的过渡，缓动是源码里的 cubic-bezier(.22,.8,.24,1)。没有仪表盘墙，没有彩虹渐变。点「重播」或滚出再滚回来可以再看一遍。

怎么操作 · 为什么新鲜
怎么操作
点「重播」，七根柱子从左到右依次长高，顶部总数跟着跳到最终值
为什么新鲜
柱子不是一起出现，而是错峰长高——先看到趋势，再看到总数，数字跳动给了一个落点
关键参数
  • 取自源码：--purple: hsl(250, 80%, 62%)；--purple-fade: hsla(250, 100%, 75%, .12)；灰阶 --gray-1: hsl(140, 8%, 96%)、--gray-3: hsl(140, 6%, 87%)、正文近 hsl(140, 6%, 15%)
  • 取自源码：@keyframes fx-progress{to{width:100%}}、fx-preview-in 从 translateY(8px) 起；缓动 cubic-bezier(.22, .8, .24, 1)；--time: .2s
  • 柱高序列与「12.4k / Unique visitors」文案是 demo 占位（原站英雄区是插画+仪表盘截图，未逐像素抄）
  • 柱子依次 delay 40ms 是 demo 增强；减少动态时直接显示终态

Ultrahuman · 给活动贴一枚彩色标签

Timeline 空着 → 点 Add a tag → 彩色胶囊落位
  1. 1Timeline 还是空的：No events yet
  2. 2点 Add a tag，给当天的活动贴一枚标签
  3. 3标签落下来就是一枚彩色胶囊，同一行还有 Log period / Log food 等入口
  4. 4底部 RING / METABOLISM / HOME / ZONES / PROFILE 五键

Mobbin 原图 · 未改动 · 299×678

Ultrahuman 的 Timeline 空着的时候不催你记东西，只放一排很轻的入口：Add a tag、Log period、Add an activity、Log food。点 Add a tag，给当天的活动贴一枚标签，标签落下来就是一枚彩色胶囊——分类这件事被做成了一个很小的动作，而不是一张表单。值得学的点：空状态不留白给焦虑，留给下一步动作。

Placify 的地图不先给你一堆图钉，先浮出一张地点卡：Central Park，带一张照片和一个 +。点 +，这个地方就收进你的地图；点开卡片是地点详情——照片、笔记、Park 标签。值得学的点：地图上的「收藏」先是一张卡，再是一个点。
