ChatLab · 头像胶囊选择条

一排头像胶囊，点谁选谁

已选：阿月

gpt888 · 模糊文字切换

订单步骤的词，糊一下再换

订单进度 · 点卡片换一步

第 1 步 选套餐

gpt888 的订单进度条上，步骤词不是硬切的：旧词先 blur(2px) 沉下去 4px，新词再从模糊里浮上来，整个切换只有 0.15 秒。这个 demo 把三步订单状态做成自动轮换，点一下也能手动换——换词这件事，糊一下比闪一下体面。

DigVPS · 网格格子闪现

淡网格上，格子一个一个亮起来

格子自己亮 · 不用点

DigVPS 首屏的底是一张很淡的网格，格子不是一次全亮，而是像有人在远处一个一个点灯：6 秒 ease-in-out 慢慢浮现，亮一下又暗回去。这个 demo 把格子放大了一点，sky-500 的光只给 14% 的透明度——背景就该是背景，抢戏就输了。

Lthero · 线描门牌入口

一块线描门牌，一块晃动的 OPEN 牌

门牌会晃 · 原站是暗色桌面，这里换成浅底对照

Crumbl Cookies · 点心单数量步进器

一行一个 − 0 +，底部合计实时跟
  1. 1粉色顶栏只写 Single（1/1 Selected）：选了 1 种里的 1 个
  2. 2每行饼干右边就是 − 0 + 步进器，不用进详情页改数量
  3. 3Vanilla Chocolate Gelato Cookie 已经是 1，其余是 0
  4. 4底部黑胶囊 Add To Bag，合计 US$5.29 跟着数量走

Mobbin 原图 · 未改动 · 299×678

Crumbl 的点单页把数量做成了行内步进器：每一行饼干右边就是 − 0 +，不用进详情、不用弹编辑框，点一下数字就变，底部黑胶囊的合计跟着跳。粉色顶栏只说一件事——Single（1/1 Selected），选了什么、多少钱，一眼到底。

Blue Apron · 菜谱筛选滑块

四组滑块，一次筛完
  1. 1TOTAL TIME 滑到 45 分钟：从备菜到上桌的总时间
  2. 2ACTIVE TIME 滑到 30+：真正动手的时间另算一根
  3. 3CALORIES 是双头滑条：MIN 0 到 MAX 1,200+
  4. 4底部 Clear all 清空，蓝色 Apply 胶囊才出结果

Mobbin 原图 · 未改动 · 299×678

Blue Apron 的筛选页没有一堆复选框，只有四根滑条：总时间、动手时间、热量、蛋白质，每根下面都标着刻度，拖到哪算到哪。筛完点右下角的蓝色 Apply 胶囊才出结果——筛选是筛选，浏览是浏览，两件事不搅在一起。
