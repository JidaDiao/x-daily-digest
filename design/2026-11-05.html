Lthero · 把桌上的东西甩出去，告诉你飞了几厘米

暗色桌面 · 拖拽惯性 · 速度每帧 ×0.92 衰减 · 黑胶囊报距离

按住物件，用力一甩

FRAGILE
1¢

松手时取最后几帧的速度，每帧乘 0.92 慢慢停，碰到桌边回弹一点，手感像推一张纸。停下后按 37.8px = 1cm 换算，不到 8cm 说「滑了」，再远说「飞了」，胶囊带一点过冲弹出。原站暗色桌面，请打分决定要不要进叼报。

怎么操作
按住桌上的物件拖动再松手：它带着惯性滑出去并慢慢停下，左下角弹出「飞了 12.4 cm」胶囊，破纪录时多一个「新纪录 ✦」。
为什么新鲜
甩东西本身没用，但它会把距离换算成真实厘米告诉你，还记你的最好成绩，一个小玩具就让桌面有了手感。
关键参数
  • 衰减 0.92/帧，拖动阈值 4px，37.8px = 1cm（lthero token 源码）
  • ≥1.5cm 才弹胶囊；<8cm「滑了」，否则「飞了」
  • 胶囊 rgba(20,20,18,.86) + 描边 rgba(198,255,61,.35)，弹入 cubic-bezier(.3,1.6,.5,1)

Obsidian · 点一个笔记，只留它和它的邻居

笔记关系图 · 节点大小按连线数 · 选中后非邻居淡到 .2 · 可拖

点一个节点 · 按住可拖

节点大小 = clamp(√(连线数+1)×3, 8, 30)，越核心的笔记越大，一眼看出主干。选中时只动透明度，不动布局，所以你不会丢失位置感；透明度用 0.9 的插值慢慢过去，不是瞬间切换。官网首页的图谱就是这样（PIXI 绘制，graph.js 源码核对）。

Web关系图聚焦拖拽暗色交互
obsidian.md ↗
怎么操作 · 为什么新鲜
怎么操作
点图谱里任意一个圆点：它多一圈描边、标签往下让开，和它相连的点和线保持亮，其余全部淡到 20%；按住拖动节点，连线跟着走；点空白处恢复。
为什么新鲜
关系图最怕一团乱麻，这里不靠缩放和筛选，只用「一点就把无关的淡下去」就让结构自己浮出来。
关键参数
  • 非邻居透明度 0.2（源码 ie=.2），插值系数 0.9/帧
  • 节点半径 clamp(√(w+1)×3, 8, 30)；选中节点加描边环，标签下移 15px（源码）
  • 配色：底 #1e1e1e、点 #a3a3a3、强调 Obsidian 紫 #a88bfa

Spline · 标题里的词一点，弹出一串头像

Hero 标题 · 词下划线 → 头像叠片胶囊（错开 50ms 弹入）· 3D 选框

点带下划线的词

Your and , building and shipping in

胶囊只走 8px 位移加淡入，很克制；里面的头像用带过冲的曲线 cubic-bezier(.2,.9,.3,1.35) 从 0.4 放大，每个错开 50ms，像一个个探出头。下划线只有 1.5px，平时是深灰，激活才变亮，提示可点但不吵。选框四角 7px 小方块是设计工具的通用语言。官网 CSS 核对。

怎么操作 · 为什么新鲜
怎么操作
点标题里带下划线的「team」或「agents」：下划线变亮，词上方弹出一颗黑色胶囊，四个头像从小到大依次蹦出来；点「3D」会被设计工具那种蓝色选框框住，四角带拖拽手柄。
为什么新鲜
把「谁在用」这种社会证明藏进标题的词里，不占版面，点到才出现；「3D」被选框框住，直接说明这是个设计工具。
关键参数
  • 胶囊 #101010 + 1px #2e2e2e，圆角 999px；进场 opacity .2s + transform .35s cubic-bezier(.2,.8,.2,1)（源码）
  • 头像 32px，-5px 叠压，2px 外圈；scale(.4)→1，.45s cubic-bezier(.2,.9,.3,1.35)，错开 50/100/150/200ms（源码）
  • 头像色 #f2c879 / #e39fd8 / #8eb2f2 / #000，最后一颗「+12」；选框 1.5px #8eb2f2 + 7px 角柄

Cosmos · 按住一张图，收进合集

灵感瀑布流 → 底部提示「Hold elements to save」→ 按住 → 合集底板 → 勾选 → Done
  1. 0s瀑布流，底部黑胶囊「Hold elements to save」
  2. ~2s按住图片，背景压暗
  3. ~3s合集底板升起：Profile / Create new collection
  4. ~5s点空心圆变黑色对勾，Done 收起

Mobbin 原视频 · 已压缩、无声

一句话亮点：收藏不用找按钮，按住图片本身就行，底部常驻一颗黑胶囊提示「Hold elements to save」。值得学：和你 4★ 的 Atoms 按住、Raindrop 拖进合集是同一路子，动作直接落在内容上；选合集时右侧是空心圆，点一下变成黑色对勾，反馈干脆。
